📖 How It Works

The simulator evaluates a list of Microsoft Purview data-access policies against a subject (user/group/service principal), a resource (Azure data source), and an action.

Evaluation rules

  • Explicit Deny wins – if any matched statement has effect Deny, access is denied regardless of Allow statements.
  • Default deny – if no policy matches, access is denied.
  • Subject wildcards ("id": "*") match all identities.
  • Resource wildcards ("resource_path": "*") match any resource.
  • Scope inheritance – a policy on a parent resource path covers child paths.

Supported actions

  • Microsoft.Purview/accounts/data/read
  • Microsoft.Purview/accounts/data/modify
  • Microsoft.Purview/accounts/scan/read
  • Microsoft.Purview/accounts/devops/read
  • Microsoft.Purview/accounts/devops/modify
